Acerca de Mí

Soy Michel Díaz, desarrolladora de software especializada en backend y bases de datos. Me dedico a crear soluciones eficientes, seguras y escalables para aplicaciones web y sistemas empresariales. He trabajado en proyectos completos, desde el análisis de requerimientos hasta la implementación y soporte, colaborando con equipos multidisciplinarios.

Utilizo frameworks como Spring Boot y .NET, así como sistemas de gestión de bases de datos como SQL Server, Oracle y Sybase en diferentes proyectos. También trabajo con Docker y desarrollo APIs RESTful, lo que me permite abordar proyectos de manera integral. Me apasiona construir aplicaciones dinámicas y centradas en el usuario, aplicando metodologías ágiles y buenas prácticas de desarrollo.
